Privacy Policyนโยบายความเป็นส่วนตัว

Short version: we collect nothing. Your scripts go to Google only when you generate a take or a preview, with your own key, and everything else stays on your Mac.สรุปสั้นๆ เราไม่เก็บข้อมูลใดๆ บทของคุณจะถูกส่งไปที่ Google เฉพาะตอนที่คุณสร้าง take หรือ preview ด้วย key ของคุณเอง นอกนั้นอยู่ในเครื่องของคุณทั้งหมด

Last updatedอัปเดตล่าสุด 2026-10-24

The appตัวแอป

  • No accounts, analytics or tracking. The app has no telemetry, crash reporting or update checks, and no server of ours to talk to.ไม่มีบัญชีผู้ใช้ ไม่มี analytics ไม่มีการติดตาม แอปไม่มี telemetry ไม่ส่งรายงาน crash ไม่เช็กอัปเดต และไม่มีเซิร์ฟเวอร์ของเราให้ติดต่อ
  • Projects and takes stay local, as files in ~/Library/Application Support/AI Voice Manager. They leave your Mac only if you export them yourself.โปรเจกต์และ take อยู่ในเครื่อง เป็นไฟล์ใน ~/Library/Application Support/AI Voice Manager และจะออกจากเครื่องก็ต่อเมื่อคุณ export เอง
  • Settings such as language, appearance, currency, tier, favourite voices, open panels, the Ollama model and the Quick preview voice are stored in macOS user defaults.การตั้งค่า เช่น ภาษา ธีม สกุลเงิน tier เสียงที่ชอบ แผงที่เปิดอยู่ โมเดล Ollama และเสียง Quick preview เก็บใน user defaults ของ macOS
  • History (your last edits and pinned states) lives in memory while the app is open and is gone when you quit.History (การแก้ไขล่าสุดและสถานะที่ปักหมุด) อยู่ในหน่วยความจำระหว่างที่แอปเปิดอยู่ และหายไปเมื่อปิดแอป

Google Gemini TTSGoogle Gemini TTS

  • Generate sends the project's unmuted scenes — their text, expression tags, styles, speaker names, voices and model — straight from your Mac to Google's Gemini API. Generate preview sends just that one scene. Test connection only lists one model.Generate ส่งฉากที่ไม่ได้ปิดเสียงของโปรเจกต์ ได้แก่ ข้อความ tag ของ expression สไตล์ ชื่อผู้พูด เสียง และโมเดล จากเครื่องคุณไปที่ Gemini API ของ Google โดยตรง Generate preview ส่งไปเฉพาะฉากนั้นฉากเดียว Test connection แค่ขอรายชื่อโมเดลหนึ่งรายการ
  • The request uses your own API key, so Google's terms and privacy policy apply to it. On the free tier, Google may use your text and audio to improve its products; with billing on, it says it doesn't.คำขอใช้ API key ของคุณเอง จึงอยู่ภายใต้ข้อกำหนดและนโยบายความเป็นส่วนตัวของ Google ถ้าใช้ free tier Google อาจนำข้อความและเสียงไปพัฒนาผลิตภัณฑ์ ถ้าเปิด billing Google ระบุว่าไม่นำไปใช้
  • Your key is stored in your macOS Keychain and sent only to Google, in a request header — never in a URL, a project file or a take.key ของคุณเก็บใน Keychain ของ macOS และส่งไปที่ Google เท่านั้น ใน header ของคำขอ ไม่อยู่ใน URL ไฟล์โปรเจกต์ หรือ take
  • To tell you when the internet is down or slow, the app times a small request to Google's API address when the network changes and once a minute. It carries no key and none of your content.เพื่อบอกเมื่ออินเทอร์เน็ตหลุดหรือช้า แอปจับเวลาคำขอเล็กๆ ไปยังที่อยู่ API ของ Google เมื่อเครือข่ายเปลี่ยนและทุกหนึ่งนาที คำขอนี้ไม่มี key และไม่มีเนื้อหาของคุณ

On your Mac onlyเฉพาะในเครื่องของคุณ

  • Quick preview uses the Mac's own voices. Nothing is sent anywhere.Quick preview ใช้เสียงของ Mac ไม่ส่งอะไรออกไป
  • Ollama runs on your Mac at localhost:11434. Polish and Add pauses send it one scene; the AI Agent sends it the project scene by scene with your question. None of it leaves the machine.Ollama ทำงานในเครื่องที่ localhost:11434 Polish และ Add pauses ส่งไปหนึ่งฉาก AI Agent ส่งโปรเจกต์ทีละฉากพร้อมคำถามของคุณ ทั้งหมดไม่ออกนอกเครื่อง

This websiteเว็บไซต์นี้

  • The site is hosted on GitHub Pages. GitHub may log visits as described in the GitHub Privacy Statement.เว็บไซต์นี้โฮสต์บน GitHub Pages ซึ่ง GitHub อาจบันทึกการเข้าชมตาม GitHub Privacy Statement
  • Pages load icons from unpkg.com, and the Download page asks the GitHub API for the latest version. No cookies, no analytics.หน้าเว็บโหลดไอคอนจาก unpkg.com และหน้า Download ถาม GitHub API เพื่อหาเวอร์ชันล่าสุด ไม่มี cookie ไม่มี analytics
  • Your language choice is saved in your browser's localStorage and never sent anywhere.ภาษาที่เลือกเก็บใน localStorage ของเบราว์เซอร์ และไม่ถูกส่งไปไหน
